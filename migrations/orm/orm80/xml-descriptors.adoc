= Shared XML descriptor behavior
:toc:

link:index.adoc[Hibernate ORM 7.4 to 8.0 migration]

[[xml-descriptors]]
The recipes identify XML by root element and namespace, not filename.
Unrelated XML is ignored.

== Supported inputs

[cols="1,2,1,2,1",options="header"]
|===
|Descriptor |Root namespace |Root element |Version update |Recipe

|JPA persistence
|`https://jakarta.ee/xml/ns/persistence`

|3.0, 3.1, 3.2 -> 4.0

Each recipe updates its document’s content together with the root `version` and the matching canonical `xsi:schemaLocation` pair when present. Missing schema locations are not added. Unrelated schema pairs and formatting are preserved. Hibernate schema locations may use HTTP or HTTPS; canonical HTTP schema URLs are upgraded to HTTPS, including in documents already marked as version 8.0.

== Manual review

Unsupported or missing versions, conflicting schema metadata, and noncanonical matching schema URLs are left unchanged and reported through `SkippedMigrations`. Older Java EE namespaces, Hibernate mapping schema 3.1.0, and legacy hbm.xml are outside this migration. These recipes cover the changes described in their recipe sections; they are not general validators or converters for every schema difference.

== Document-wide conflicts and repeated runs

Each schema family has one selectable recipe that transforms supported content
and updates version/schema metadata together. Package descriptor and Hibernate
comment conversions are part of their respective descriptor recipes.
A content conflict cancels all changes to that document and is reported in
`SkippedMigrations`; other documents remain eligible. This also applies to documents
already carrying the target version. Re-running a successful migration makes no
further changes.

== Selecting only XML conversions

To run only XML conversions, select those recipes directly:

[source,groovy]
----
rewrite {
    activeRecipe("org.hibernate.migration.recipes.jpa4.MigratePersistenceXml")
    activeRecipe("org.hibernate.migration.recipes.jpa4.MigrateOrmXml")
    activeRecipe("org.hibernate.migration.recipes.orm80.MigrateMappingXml")
    exportDatatables = true
}
----
