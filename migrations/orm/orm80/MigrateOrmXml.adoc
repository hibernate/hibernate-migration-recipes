= MigrateOrmXml

link:index.adoc[Hibernate ORM 7.4 to 8.0 migration]

[[_MigrateOrmXml]]
Recipe name is `org.hibernate.migration.recipes.jpa4.MigrateOrmXml`.

Migrates Jakarta Persistence entity-mapping descriptors to version 4.0.

== Conversions

Updates the root `version` and the matching canonical `xsi:schemaLocation`
pair when present. Descriptor content is otherwise preserved.

== Supported inputs

An `entity-mappings` root in the Jakarta Persistence mapping namespace, with
version 3.0, 3.1, 3.2, or 4.0. Custom filenames and namespace prefixes are supported.
See link:xml-descriptors.adoc[shared XML descriptor behavior] for shared eligibility and schema metadata rules.

== Manual review

Unsupported or missing versions, conflicting metadata, and noncanonical
matching schema URLs remain unchanged and are reported in `SkippedMigrations`.
Older Java EE namespaces are outside this migration.
